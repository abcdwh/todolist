개인정보처리방침

시행일: 2026년 9월 10일

「오늘할일」(이하 "본 앱")은 사용자가 날짜별 할 일을 기록하고 관리하는 웹 애플리케이션입니다. 본 앱은 사용자의 개인정보를 수집하지 않는 것을 원칙으로 하며, 아래와 같이 데이터를 처리합니다.

요약
본 앱은 별도의 서버를 운영하지 않습니다. 작성한 할 일은 사용자의 기기와 사용자 본인의 Google 드라이브에만 저장되며, 개발자는 이 데이터에 접근할 수 없습니다.

1. 수집하는 정보

본 앱은 회원가입을 요구하지 않으며, 이름·연락처·주소 등 어떠한 개인 식별 정보도 수집하지 않습니다. 사용자가 앱에 직접 입력한 할 일 내용, 분류(업무/개인), 메모만이 처리 대상입니다.

2. 데이터의 저장 위치

  • 기기 내 저장: 할 일 데이터는 기본적으로 사용자가 사용하는 브라우저의 로컬 저장소에 보관됩니다. 이 데이터는 해당 기기를 벗어나지 않습니다.
  • Google 드라이브 동기화(선택): 사용자가 직접 Google 계정으로 로그인한 경우에 한해, 할 일 데이터가 사용자 본인의 Google 드라이브에 저장됩니다.

3. Google 계정 및 드라이브 이용

본 앱은 여러 기기 간 데이터 동기화를 위해 Google 드라이브 연동 기능을 선택적으로 제공하며, 다음 권한만을 요청합니다.

  • https://www.googleapis.com/auth/drive.appdata

이 권한은 사용자의 Google 드라이브 내에 생성되는 본 앱 전용 폴더에만 접근할 수 있습니다. 사용자가 드라이브에 보관 중인 문서, 사진, 그 밖의 파일에는 접근할 수 없으며 조회조차 불가능합니다. 본 앱은 이보다 넓은 범위의 권한을 요청하지 않습니다.

동기화된 데이터는 사용자 본인의 Google 계정에 귀속됩니다. 개발자는 사용자의 저장 데이터를 열람·수집·보관하지 않으며, 그럴 수 있는 기술적 수단도 가지고 있지 않습니다.

4. 제3자 제공 및 활용 제한

본 앱은 사용자 데이터를 제3자에게 판매·양도·공유하지 않습니다. 광고를 게재하지 않으며, 광고 목적이나 인공지능 모델 학습 목적으로 데이터를 사용하지 않습니다. Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.

5. 데이터 보관 및 삭제

사용자는 언제든지 다음 방법으로 데이터를 삭제할 수 있습니다.

  • 앱 내에서 개별 할 일을 삭제
  • 브라우저의 사이트 데이터 삭제 기능 이용
  • Google 계정 권한 관리 페이지에서 본 앱의 접근 권한 철회

권한을 철회하면 본 앱은 더 이상 사용자의 드라이브에 접근할 수 없습니다. 드라이브에 저장된 앱 데이터 파일은 사용자가 Google 드라이브 설정의 앱 관리 항목에서 직접 삭제할 수 있습니다.

6. 아동의 개인정보

본 앱은 개인 식별 정보를 수집하지 않으므로 연령과 무관하게 이용할 수 있으나, 만 14세 미만 아동은 법정대리인의 지도 아래 이용할 것을 권장합니다.

7. 보안

Google 계정 인증은 Google이 제공하는 표준 OAuth 2.0 절차를 통해 이루어지며, 본 앱은 사용자의 Google 비밀번호를 요구하거나 저장하지 않습니다. 통신은 HTTPS로 암호화됩니다.
